Privacy and data use

Know where your information goes.

AccessWear is a public hackathon prototype by Lila Hu. This notice explains the information used by each feature so you can decide what to share. Last updated 15 August 2026.

Clothing conversation

Your message, a bounded number of recent chat messages, and validated clothing requirements are sent through the AccessWear Cloudflare Worker to the OpenAI API. OpenAI helps interpret the language of your request; application code decides which fictional products match.

Do not include a diagnosis, medical record, contact details or other information that is not needed to describe your clothing needs. AccessWear requests API processing with storage disabled, but provider security and abuse-monitoring retention may still apply. Read OpenAI's API data controls.

Saved measurements

Measurements are stored only in this browser's session storage. They are used locally to compare your values with fictional garment data. They are not sent to OpenAI, YouCam or the alteration search. Select Reset measurements or Start over to remove them from the current browser conversation.

Virtual try-on photograph

Virtual try-on is optional. You must confirm that you are the person shown in the photograph, or that you have their permission, before uploading it. AccessWear sends the photo directly to a temporary YouCam upload location and asks Perfect Corp.'s YouCam API to create the preview. AccessWear's Worker does not store the photograph bytes.

The generated result link is kept in this browser's session storage with the recent conversation. Select Start over or close the browser session to remove the local record. Perfect Corp.'s processing and retention are governed by its YouCam privacy policy and YouCam API terms.

Alteration-service location

If you explicitly search, a town/postcode or browser-provided coordinates are sent through the Worker to OpenStreetMap search services. The location is used for that search, is not added to your clothing conversation, and is kept only in page memory until refresh. Read the OpenStreetMap privacy policy.

Hosting and security

Cloudflare hosts the site and Worker and provides Turnstile abuse protection. Like most hosting providers, it may process technical request information needed to deliver and protect the service. Read the Cloudflare privacy policy.

Your choices

  • You can use clothing chat without virtual try-on.
  • You can search for alterations without browser geolocation.
  • You can omit optional measurements.
  • You can select Start over to clear the browser conversation.

Privacy questions can be sent to the entrant through the AccessWear Devpost project profile. This prototype is not intended for children or for medical advice.
